# CivicConnect Mobile

Flutter client for citizens to submit and track civic reports.

## Local development

```bash
flutter pub get
flutter run
```

Set the API endpoint using the local environment configuration described in
the [root README](../README.md). Do not commit `mobile/.env`.

## Validation

```bash
flutter analyze
flutter test
```
